## ✨ ویژگی‌ها

- اتصال امن به پایگاه‌داده با استفاده از PDO  
- پیاده‌سازی کامل عملیات CRUD  
- ساختار ساده و قابل فهم برای مبتدیان  
- استفاده از توابع آماده PHP برای تعامل با پایگاه‌داده

## ⚙️ پیش‌نیازها

- PHP نسخه 5.6 یا بالاتر  
- MySQL  
- سرور محلی مانند XAMPP یا WAMP

## 🚀 نصب و راه‌اندازی

1. مخزن را کلون کنید:

   ```bash
   git clone https://github.com/MansourLiaghat/pdo.git
   ```

2. پایگاه‌داده را ایجاد کنید:

   - یک پایگاه‌داده با نام دلخواه ایجاد کنید.  
   - جدول `users` را با ساختار مناسب ایجاد کنید.

3. فایل `connect.php` را باز کرده و اطلاعات اتصال به پایگاه‌داده را تنظیم کنید:

   ```php
   $host = 'localhost';
   $db   = 'your_database_name';
   $user = 'your_username';
   $pass = 'your_password';
   ```

4. پروژه را در مرورگر باز کنید و از فایل‌های `insert.php`, `select.php`, `update.php`, `delete.php` برای عملیات مختلف استفاده کنید.

## 🧪 نحوه استفاده

- **افزودن کاربر جدید**: از `insert.php` برای افزودن کاربر جدید استفاده کنید.  
- **نمایش کاربران**: `select.php` لیستی از کاربران را نمایش می‌دهد.  
- **به‌روزرسانی اطلاعات کاربر**: با استفاده از `update.php` اطلاعات کاربر را ویرایش کنید.  
- **حذف کاربر**: `delete.php` برای حذف کاربر مورد استفاده قرار می‌گیرد.
